# iDominiqe — Spatial Liquid Glass Portfolio & Web Studio

Interactive **Liquid Glass / Spatial OS** portfolio & web creation studio hosted at **[https://idominiqe.com](https://idominiqe.com)**.

## Features
- **Liquid Glass UI**: Multi-layer frosted refraction (`backdrop-filter: blur`), specular rim highlights, mouse-tracking caustic spotlight, and floating 3D parallax glass geometry.
- **6 Color Palettes & 3 Lighting Modes**: Switch instantly between `Aurora`, `Vision`, `Cyber`, `Solar`, `Sunset`, and `Arctic` palettes across `Dark`, `Light`, and `Prism` lighting modes.
- **Background & FX Studio**: Choose between the live animated mesh gradient, preset spatial environments, or upload/paste any custom background wallpaper with live blur, dimming, mouse glow, and 3D parallax sliders.
- **Multilingual (`EN`, `RO`, `FR`, `BG`, `RU`)**: Zero-reload instant language switching across all interface elements, projects, and service briefs.
- **Interactive Service Configurator**: Toggle desired features (Liquid Glass UI, Three.js 3D Scene, Parallax & Cursor, Multi-Language, Cloudflare DNS, Mobile/Wix Embed) to generate a live delivery estimate and project brief.
- **Portfolio Showcase & Live Preview**:
  - [Smart-City-Led 3D](https://smartcity.idominiqe.com/) — 3D Solar Smart City & EV Ecosystem
  - [NEO® HUWART 3D](https://smartcity.idominiqe.com/) — 3D Solar & Vegetated Parking Canopies + Supermarket
  - [LOCLIM / NEO Clim® 3D](https://www.smart-city-led.com/loclimaccueil) — 360° 3D HVAC Simulator (Wix Embed)
  - [BLAZE // RE41](https://blaze.idominiqe.com/) — Tactical 3D Cyberpunk HUD
  - [CYBER OF X](https://cyber.idominiqe.com/) — WebGL Metaverse Portal
